## B300 서버와의 연결

기준값: 사용 가능 HBM 약 2.1 TB(GPU당 약 270 GB). 가중치 크기 = 파라미터 수 × 바이트(FP16 2, FP8 1, FP4 0.5)입니다. 2.1 TB에서 가중치를 빼고, 여유분을 남긴 나머지가 KV 캐시 몫입니다.
