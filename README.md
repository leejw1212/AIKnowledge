- 각 폴더의 `README.md`에 그 가지의 세부 마인드맵과 주제 목록이 있습니다.
- 주제별 노트 파일에는 제목과 "공부할 질문"만 들어 있습니다. 공부하면서 요약, 핵심 개념, 참고 자료를 직접 채워 나갑니다.
- 질문에 답할 수 있게 되면 체크박스를 체크합니다.
